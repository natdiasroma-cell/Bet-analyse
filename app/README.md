# Application Android `Bet-Analyse`

Cette application sera développée en **Kotlin** avec Jetpack Compose.

## Fonctionnalités prévues
- Analyse sportive basée sur les APIs backend
- Affichage des analyses avancées et des cotes
- Suivi des prédictions passées

---
### Installation
1. Ouvrir ce dossier dans Android Studio
2. Configurer un émulateur ou appareil physique
3. Suivre les étapes pour compiler et exécuter le projet.
